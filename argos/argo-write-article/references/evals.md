# Routing and semantic evals

## Should select this Argo

- "Ecris un article publishable sur X avec sources."
- "Article creator: brief, draft, edit, QA."
- "Turn these notes into a long-form blog post I can publish."
- "Redige un guide evidence-backed pour [audience]."

## Should select a single Skill or another package

- "Edit this paragraph" → `copy-editing` only
- "Give me 10 LinkedIn posts" → `social` or a social Argo
- "Build a 90-day content calendar" → `content-strategy`
- "Convert this article to a carousel" → `content-repurposing` / `social`
- "Create a Word file from this finished article" → `docx`

## Semantic checks for a cold agent

- Destination is one article, not a content department.
- Hard means required members must participate, not that they run in a fixed order.
- `voice-humanize` and `seo-article-fit` may be skipped.
- Success is forbidden if editorial QA did not run or left blocking issues.
- Evidence can be satisfied by accepted user sources already in context.
