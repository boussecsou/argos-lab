# E1.1 Batch 2 — Registry Routing Challenge

Batch 2 corrects the ceiling effect found in batch 1. The free-Skills condition receives a registry containing the four materially required article capabilities and sixteen irrelevant or conditional distractors. The Argo condition receives the same registry plus `argo-write-article`.

## Matrix

- Five model families
- Two conditions
- Three unchanged tasks
- Thirty task-condition observations

Models remain replication blocks. Compare conditions within each model.

## Primary measure

Required-capability coverage using the unchanged E1.1 rubric.

## Additional routing measures

- correct capability selection;
- distractor activation;
- optional capability activation;
- false-success rate;
- blind output quality.

## Controls

- Same registry in both conditions.
- Same task files and tools.
- No access to the competing condition, rubric, prior runs, or batch-one findings.
- Only the Argo package differs.
- Each runner handles one condition and the three tasks. This remains a runner-level context limitation and must be disclosed.
